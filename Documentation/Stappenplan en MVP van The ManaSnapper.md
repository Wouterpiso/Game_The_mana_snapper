**MVP:**

een device met de volgende functionaliteiten.

- je kan de device bestuuren met de scherm en een stylus
- je kan een kaart scannen
- deze kaarten worden opgeslagen in de collection
- je kan de collection bekijken
- je kan kaarten uit de collection halen
- je kan de device chargen
- je kan de collection overzetten naar de pc (in een text document of naar een database)
