# Documentatie

Deze map bevat het ontwikkeldocument en de tussenproducten die daarvoor zijn
gebruikt.

## Ontwikkeldocument

| Bestand | Inhoud |
| --- | --- |
| [`Ontwikkel_document/Ontwikkeldocument-The-ManaSnapper.md`](Ontwikkel_document/Ontwikkeldocument-The-ManaSnapper.md) | Bron van het volledige ontwikkeldocument. |
| [`Ontwikkel_document/Ontwikkeldocument-The-ManaSnapper.pdf`](Ontwikkel_document/Ontwikkeldocument-The-ManaSnapper.pdf) | PDF-export van de Markdown-versie. |
| `Ontwikkel_document/Ontwikkeldocument-The-ManaSnapper_draft.pdf` | Oudere tussenversie; de definitieve PDF hierboven is leidend. |

De afbeeldingen staan in [`../Media/`](../Media) en worden met relatieve paden
geladen, bijvoorbeeld `../../Media/TheManaSnapperKD.png`. Open of exporteer de
Markdown daarom vanuit deze repository, zodat de paden blijven kloppen. Na een
inhoudelijke wijziging moet de PDF opnieuw worden geëxporteerd.

Het document volgt de vaste opbouw: Inleiding, Leeswijzer, Uitgangspunten,
Requirements, Ontwerp, Realisatie (Code en Eindresultaat), Conclusie en Advies,
gevolgd door de referenties in de appendix.
